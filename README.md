# Pocket-Coach
Pocket golf swing helper supported by AI. Aimed to help golfers of any skill level improve their game by providing customized feedback to the user.

Aimed to run on phone with a free and subscription based version, providing varied benefits.

Primary focus is to be able to scan your swing using video and have an embeded ai calculate and rate your swing, and what you can improve.

Website link (demo): jmanzari2.wixsite.com
